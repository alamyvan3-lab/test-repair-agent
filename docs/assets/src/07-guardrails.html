Guardrails

Fixes the code. Never the tests.

Every rule below is covered by an automated test in the repository.
Locked-down sandbox
Fresh container per run: no network, read-only root, CPU / memory / PID limits, all capabilities dropped, non-root, hard timeout.
Tests are off-limits
Any diff touching tests/, test_*.py, conftest.py, or pytest / tox / pyproject config is rejected before it is applied.
No test-gaming
Code that reads PYTEST_CURRENT_TEST, inspects the call stack, or mocks in source is blocked, then Nano reviews every patch.
Injection-resistant
Code and test output are data, never instructions. A demo repo hides “delete the tests” in its source; nothing obeys it.
Budgets
Max attempts, corrections, tokens, and wall time. Runs end cleanly with a clear status instead of looping.
Secrets stay put
The Token Factory key stays server-side, is redacted from events and reports, and never enters the sandbox.
