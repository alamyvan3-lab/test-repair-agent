How Suture works

Localize, patch in parallel, verify, minimize

NVIDIA Nemotron Ultra for the hard reasoning, Nano for the frequent cheap calls, both on Nebius Token Factory.
1
Run tests
fresh locked-down sandbox; parse every failure
2
Localize
SBFL: lines run by failing tests, scored with Ochiai
3
Triage
raw pytest output to compact JSON
NANO
4
Patch ×3
diagnosis + unified diff, three candidates in parallel
ULTRA
5
Validate
paths, no test edits, no test-gaming, compiles, git apply --check
+ Nano review
6
Vote & verify
same-AST candidates merge; distinct ones run in parallel sandboxes
7
Minimize
drop any change the tests do not need
Still red or regressed? Revert, feed the history back to Ultra, retry (up to 5 attempts). Green? Ship the patch + explanation.
Every step is a streamed event with model, tokens, and latency. Plain Python + FastAPI, no agent framework.
